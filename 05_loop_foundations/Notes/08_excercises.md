# 🟢 Beginner Exercises

1. Print numbers from 1 to 10 using a `for` loop.

2. Print numbers from 10 to 1 using a `while` loop.

3. Print the multiplication table of a given number.

4. Calculate the sum of numbers from 1 to N.

5. Calculate the factorial of a number.

6. Count the number of characters in a string without using `len()`.

7. Count vowels in a string.

8. Print only even numbers from a list.

9. Print only odd numbers from a list.

10. Reverse a string using a loop.

11. Find the largest number in a list.

12. Find the smallest number in a list.

13. Count occurrences of a given element in a list.

14. Print every key and value from a dictionary.

15. Print every character of a string on a separate line.

---

# 🟡 Intermediate Exercises

16. Search for a student in a list using `break`.

17. Skip negative numbers using `continue`.

18. Validate scores (0–100) while ignoring invalid entries.

19. Process only active users from a list of dictionaries.

20. Stop processing orders when a cancelled order is found.

21. Find the first duplicate element in a list.

22. Build a countdown timer.

23. Generate the Fibonacci sequence.

24. Simulate login attempts with a maximum of three tries.

25. Validate usernames (minimum length, no spaces).

26. Search for an employee using `for-else`.

27. Check whether a number is prime.

28. Simulate retry logic using `while-else`.

29. Build a simple menu using `while`.

30. Print a 5×5 grid using nested loops.

---

# 🔴 Advanced Exercises

31. Flatten a nested list using loops.

32. Find common elements between two lists.

33. Remove duplicates while preserving order.

34. Build a frequency counter for words in a sentence.

35. Parse a CSV file line by line.

36. Simulate processing records from a database.

37. Validate an inventory list and stop on invalid data.

38. Process orders while skipping cancelled orders.

39. Build a simple command processor using loops.

40. Implement a retry mechanism with exponential backoff (logic only).

- ✅ Write nested loops
- ✅ Solve common iteration problems
- ✅ Build small loop-driven applications
