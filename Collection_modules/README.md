# Collection Modules Projects

This folder contains six beginner-friendly console applications that demonstrate the practical use of common Python collection modules.

## Projects included

1. Website Log Analyzer - uses Counter for page visit analytics.
2. Employee Directory - uses defaultdict(list) to group employees by department.
3. Customer Support Queue - uses deque to manage waiting customers.
4. Product Inventory - uses namedtuple to store product records.
5. Settings Manager - uses ChainMap to apply layered configuration settings.
6. Recent Files Manager - uses OrderedDict to keep a recent file history.

## How to use

Each project is a small standalone Python application. Open the relevant folder and run the main script with:

```bash
python main.py
```

These examples are designed to be simple, readable, and suitable for learning how different collection types solve common programming problems.
