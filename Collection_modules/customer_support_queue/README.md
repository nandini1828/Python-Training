# Customer Support Queue

## What this project does
This project simulates a customer support queue using `deque` from the `collections` module.

## Key concepts used
- `append()` adds a normal customer to the end of the queue.
- `appendleft()` adds a VIP customer to the front of the queue.
- `popleft()` serves the next waiting customer.

## Main features
- Add regular customers.
- Add VIP customers.
- Serve the next customer.
- View the full waiting queue.
- Check the current queue length.

## Why this is useful
A queue is ideal for managing first-come, first-served systems, especially when some high-priority people need to jump ahead.
