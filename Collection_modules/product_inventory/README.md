# Product Inventory

## What this project does
This project uses `namedtuple` to store product information in a structured and readable way.

## Key concepts used
- `namedtuple` gives each field a meaningful name such as `product_id`, `name`, `price`, and `stock`.
- The inventory is stored in a list so multiple products can be managed together.

## Main features
- Add a new product.
- Display all products in a formatted table.
- Search for a product by ID.
- Show low stock items.
- Calculate the total inventory value.

## Why this is useful
Named tuples are great for keeping fixed records clear and easy to read without using full classes.
