# Website Log Analyzer

## What this project does
This project uses the `Counter` class from the `collections` module to analyze website visit logs.

## Key concepts used
- `Counter` helps count how many times each page appears in the log list.
- It is useful for finding the most visited page, top pages, and visit totals.

## Main features
- Display the total number of requests.
- Find the most visited page.
- Show the top three most visited pages.
- Search how many times a specific page was visited.
- Display a complete analytics summary.

## Why this is useful
This kind of analysis is helpful for understanding user behavior, identifying popular pages, and improving website design.
