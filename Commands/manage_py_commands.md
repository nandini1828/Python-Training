# Django manage.py Commands

---

# General Syntax

```bash
python manage.py <command>
```
---

# Start Development Server

```bash
python manage.py runserver
```

---

# Run on Custom Port

```bash
python manage.py runserver 9000
```

---

# Run on All Network Interfaces

```bash
python manage.py runserver 0.0.0.0:8000
```

---

# Check Project for Issues

```bash
python manage.py check
```

---

# Display Help

```bash
python manage.py help
```

---

# Show Version

```bash
python manage.py version
```

---

# Create a New Django App

```bash
python manage.py startapp students
```

---

# Create Migration Files

```bash
python manage.py makemigrations
```

---

# Apply Migrations to Database

```bash
python manage.py migrate
```

---

# Show SQL Generated by Migrations

```bash
python manage.py sqlmigrate <app_name> <migration_number>
```

Example:

```bash
python manage.py sqlmigrate students 0001
```

---

# Create an Administrator Account

```bash
python manage.py createsuperuser
```

---

# Open Django Interactive Shell

```bash
python manage.py shell
```

---

# Collect Static Files (Production)

```bash
python manage.py collectstatic
```

---

# Show All Registered URLs (requires django-extensions)

```bash
python manage.py show_urls
```

---

# Common Workflow

```bash
python manage.py startapp students
python manage.py makemigrations
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

---

# Best Practices

- Always activate your virtual environment before running commands.
- Run commands from the project root (where `manage.py` is located).
- Commit migration files to version control.
- Never edit migration files manually unless you understand their impact.
