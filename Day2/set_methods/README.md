# Set Methods

## Concept Overview
This package highlights how sets are used for membership, uniqueness, and mathematical set operations.

## Why It Exists
Sets are ideal for removing duplicates and comparing collections efficiently.

## Real World Use Cases
- Filtering duplicate records
- Comparing user permissions
- Finding overlaps between datasets

## Example Code
```python
from set_methods.set_utils import unique_items

values = unique_items([1, 1, 2, 3])
```

## Expected Output
A set containing only unique values.
