# Django Training Workspace

This workspace is designed for a beginner-friendly Django learning path.
It includes lesson notes, command references, and a working hotel management Django project.

## Current project
- `projects/hotel_management` — a sample Django app for hotel room booking management.

## How to use
1. Open the workspace in VS Code.
2. Read `notes/00_Workspace_Guide.md` first.
3. Follow the class notes in order from `notes/01_Class_1_Intro_To_Django.md` onward.
4. Activate a Python virtual environment and install dependencies.
5. Run `python manage.py runserver` from `projects/hotel_management`.

## Notes
- `notes/` contains structured class notes for each Django lesson.
- `commands/` contains useful Django command references.
- `projects/hotel_management/` contains the sample Django application.
- `resources/` contains future assets, diagrams, and references.

## Beginner walkthrough
- Start with `notes/00_Workspace_Guide.md` for a complete workspace tour.
- Use `notes/14_Workspace_Tour.md` to understand the folder structure and main files.

## Learning path
- Class 1: Intro to Django and web basics
- Class 2: Creating a Django project, URLs, views, templates
- Class 3: Apps, settings, manage.py, URL routing
- Class 4: Models, ORM, SQLite, migrations
- Class 5: Admin panel and CRUD
- Class 6: Django REST Framework
- Class 7: ModelViewSet and routers
- Class 8: Authentication and permissions
- Class 9: Relationships
- Class 10: Pagination, filtering, searching, ordering
- Class 11: Deployment with Docker, Gunicorn, Nginx
- Enterprise Project: Build a complete hotel management system
