# Django Training Course Roadmap

This course is designed as a step-by-step Django learning path.
Each class builds on the previous one and contains theory, examples, exercises, and practical tasks.

## Class list

1. Class 1: What is Django?
   - How the internet works
   - HTTP
   - Request & Response
   - MVC vs MVT
   - Project structure
   - Virtual environment
   - Install Django

2. Class 2: Create First Django Project
   - `runserver`
   - `urls.py`
   - `views.py`
   - Templates
   - Static files

3. Class 3: Apps, settings, and URL routing
   - Apps
   - `settings.py`
   - `manage.py`
   - Creating apps
   - URL routing

4. Class 4: Models and ORM
   - Models
   - Django ORM
   - SQLite
   - Migrations

5. Class 5: Admin panel and CRUD
   - Admin panel
   - CRUD operations

6. Class 6: Django REST Framework
   - APIView
   - Serializer
   - Response
   - Status codes

7. Class 7: ModelViewSet and routers
   - CRUD APIs
   - Routers

8. Class 8: Authentication
   - JWT
   - Permissions

9. Class 9: Relationships
   - `ForeignKey`
   - `ManyToMany`
   - `OneToOne`

10. Class 10: Pagination, filtering, searching, ordering

11. Class 11: Deployment
   - Docker
   - Gunicorn
   - Nginx

12. Enterprise Project
   - Build a complete hotel management system
   - Combine apps, APIs, authentication, deployment

## How to use these notes

- Start with `notes/01_Class_1_Intro_To_Django.md`
- Follow the class order
- Practice each exercise
- Refer to `commands/` for Django CLI commands
- Use the `projects/hotel_management` project for examples
