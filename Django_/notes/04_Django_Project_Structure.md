## What is a Django Project?

A Django Project is the complete web application.
It contains all configuration, apps, and service definitions needed to build a website or API.

Examples:

- Hotel Management System
- E-Commerce Website
- Blogging Platform
- Student Management System
- CRM Software

A project can contain one or many Django apps.

## Django Project Structure

When you create a project using:

```bash
django-admin startproject config .
```

Django generates the following structure:

```
hotel_management/
├── .venv/
├── config/
│   ├── __init__.py
│   ├── settings.py
│   ├── urls.py
│   ├── wsgi.py
│   └── asgi.py
├── manage.py
├── requirements.txt
```

## Understanding the Structure

### .venv

This folder contains the project's isolated Python environment.

Includes:

- Python interpreter
- pip
- installed packages
- activation scripts

This folder is generated automatically and should not be edited manually.

### config/

This is the configuration package of the project.
It contains important files that tell Django how to run.

Think of it as the "brain" of the project.

### manage.py

The command-line utility used to interact with Django.
It loads the project settings and exposes commands like:

- `runserver`
- `migrate`
- `startapp`
- `createsuperuser`

### requirements.txt

Stores all Python packages required for the project.
Anyone can recreate the same environment using:

```bash
pip install -r requirements.txt
```

## Project vs App

A **Project** is the complete website or API.
An **App** is a reusable module that provides one specific feature.

Example:

Project: Hotel Management
Apps inside it:

- Booking
- Rooms
- Customers
- Authentication
- Reports

Apps make a Django project modular and easier to maintain.

## How Django Starts

When we run:

```bash
python manage.py runserver
```

Django follows this flow:

1. `manage.py`
2. `settings.py`
3. `urls.py`
4. view function or class
5. optional database interaction
6. response
7. browser

## Why this Structure Matters

Benefits:

- Organized code
- Easier maintenance
- Modular design
- Better debugging
- Scalable for complex projects

Large companies often use many Django apps inside a single project.
