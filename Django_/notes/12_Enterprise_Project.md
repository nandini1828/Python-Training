# Enterprise Project

## Learning Objectives

After this project, you will be able to:

- design a complete Django application
- model real business domains
- build reusable apps
- connect APIs and frontend templates
- deploy a Django app to production

## Project Goal

Build a complete Hotel Management System.
The project should include:

- room management
- reservation booking
- customer records
- admin panel
- REST APIs
- authentication
- deployment strategy

## Suggested Apps

- `booking`
- `rooms`
- `customers`
- `authentication`
- `reports`

## What You Will Learn

- working with multiple apps
- separating responsibilities
- using DRF for APIs
- implementing authentication
- creating relationships between models
- handling pagination and filtering
- deploying with Docker and Gunicorn

## Project Features

1. Hotel room listing and availability
2. Reservation booking
3. Customer management
4. Admin dashboard
5. Room API endpoints
6. JWT authentication for APIs
7. Relationship models between rooms, reservations, and customers
8. Search, filter, and order capabilities

## How to Use This Project

Use the notes from Class 1–11 as your learning path.
Build the project incrementally:

1. Start with project and apps
2. Add models and migrations
3. Register models in admin
4. Build views and templates
5. Add APIs using DRF
6. Secure APIs with authentication
7. Deploy the application

## Summary

This enterprise project is the final application that brings all Django concepts together.
It is meant to be a portfolio-worthy system that demonstrates full-stack Django development.
