# Employee Management Project

This project provides a simple Python-based employee management system with models, services, APIs, utilities, and collection helpers.

## Structure

- `models/` contains domain models.
- `services/` contains business logic.
- `api/` contains API-facing wrappers.
- `utils/` contains validators and helpers.
- `tests/` includes example pytest tests.

## Run

```bash
python main.py
pytest
```
