# Class 10: Pagination, Filtering, Searching, Ordering

## 1. Pagination
Pagination splits long result sets into smaller pages.

Example:
- 5 records per page

## 2. Filtering
Filtering narrows results based on field values.

## 3. Searching
Searching lets users find data by keywords.

Example:
- Search by first name, last name, email, or course.

## 4. Ordering
Ordering sorts result sets by a field.

Example:
- Order by created date
- Order by name
- Order by age

## 5. In this project
- The student API supports pagination
- The API supports search by name or course
- Results can be ordered by common fields
