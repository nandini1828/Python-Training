# Python Practice Project

This project contains 5 simple Python files that help understand the basics of Python programming.

## Overview
Each file focuses on a different concept:

1. **class_objects.py**
   - Shows how classes and objects are created.
   - Explains how to define attributes and methods.
   - Helps understand the idea of a class as a blueprint.

2. **datastructures.py**
   - Covers important data structures like lists, tuples, dictionaries, and sets.
   - Also includes simple examples of stack and queue logic.

3. **datatypes.py**
   - Demonstrates different Python data types such as strings, integers, floats, booleans, lists, tuples, and dictionaries.
   - Shows how to print values and check their types.

4. **methods.py**
   - Explains common methods used with strings, lists, dictionaries, sets, and tuples.
   - Helps understand how methods are used to change or access data.

5. **oops_beginner_demo.py**
   - Shows beginner-friendly OOP concepts.
   - Includes examples for class and object, inheritance, polymorphism, encapsulation, and abstraction.

## Learning Goals
This project was created to:
- understand basic Python syntax
- learn how different data types work
- practice using data structures
- learn how methods are used
- get a simple introduction to Object-Oriented Programming

## How to Run
You can run each file separately using Python:

```bash
python3 class_objects.py
python3 datastructures.py
python3 datatypes.py
python3 methods.py
python3 oops_beginner_demo.py
```

If `python3` is not available, use:

```bash
python class_objects.py
python datastructures.py
python datatypes.py
python methods.py
python oops_beginner_demo.py
```

## Purpose of the Project
The goal of this project is to practice Python step by step and build a strong foundation for beginners.
