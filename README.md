# E-Commerce Backend using FastAPI

This project is built to learn Python, Object-Oriented Programming (OOP), and FastAPI by developing a small e-commerce backend.

## Goals

- Learn Python through real examples
- Master Object-Oriented Programming
- Build REST APIs using FastAPI
- Understand clean project architecture
