# Comprehensions & Generators Interview Questions

---

# Beginner

## 1. What is a list comprehension?

A concise way to create lists.

---

## 2. What is the syntax of a list comprehension?

```python
[
    expression
    for item in iterable
]
```

---

## 3. What is a dictionary comprehension?

A concise way to create dictionaries.

---

## 4. What is a set comprehension?

A concise way to create sets.

---

## 5. What is a generator?

A function that uses `yield` to produce values lazily.

---

## 6. Difference between return and yield?

`return`

- Ends execution.

`yield`

- Pauses execution.

---

## 7. What is lazy evaluation?

Values are generated only when required.

---

## 8. What does iter() do?

Returns an iterator from an iterable.

---

## 9. What does next() do?

Returns the next value from an iterator.

---

## 10. What is StopIteration?

The exception raised when an iterator is exhausted.
