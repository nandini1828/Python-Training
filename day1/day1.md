Day 1 - Python Fundamentals

Data Types

A data type defines what kind of value a variable can store.


Common Data Types

* str → Text
* int → Whole numbers
* float → Decimal numbers
* bool → True/False
* list → Ordered collection
* tuple → Immutable collection
* dict → Key-value pairs
* set → Unique values

Examples

name = "Karthik"
age = 21
salary = 50000.5
is_active = True

OOP (Object-Oriented Programming)

OOP is a programming approach based on Classes and Objects.

Class

Blueprint or template.

class Employee:
    pass

Object

Instance of a class.

emp1 = Employee()



Four Pillars of OOP

Encapsulation

Hiding data and controlling access.

Inheritance

One class reuses another class’s properties and methods.

Polymorphism

Same method, different behavior.

Abstraction

Hide complexity and show only required functionality.
