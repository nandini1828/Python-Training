# 2. Data Structures

Data structures are used to organize and store data efficiently.

## Covered Topics

### List
- Ordered collection
- Mutable
- Allows duplicate values

### Tuple
- Ordered collection
- Immutable
- Allows duplicate values

### Set
- Unordered collection
- Mutable
- Does not allow duplicate values

### Dictionary
- Key-value pair collection
- Mutable
- Fast data lookup

### Queue
- FIFO (First In First Out)
- Used in ticket processing systems
- Implemented using `collections.deque`
