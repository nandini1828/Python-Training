# E-Commerce API using FastAPI

## Features

- Product Management
- Customer Management
- Shopping Cart
- Order Management
- File Handling
- Logging

---

## Installation

```bash
pip install -r requirements.txt
```

---

## Run the Application

```bash
uvicorn app.main:app --reload
```
