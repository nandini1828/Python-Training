# Comprehensions Overview

This module focuses on Python comprehensions for compact iteration and transformation.

## Implemented Topics

### 1. List Comprehensions
Implemented in:

- `comprehensions/list_comprehensions.py`

Covered:
- Filtering even numbers
- Transforming values into squares

---

### 2. Dictionary Comprehensions
Implemented in:

- `comprehensions/dictionary_comprehensions.py`

Covered:
- Building number-square mappings
- Mapping words to their lengths

---

### 3. Set Comprehensions
Implemented in:

- `comprehensions/set_comprehensions.py`

Covered:
- Lowercasing and deduplicating strings
- Extracting unique even numbers

---

### 4. Nested Comprehensions
Implemented in:

- `comprehensions/nested_comprehensions.py`

Covered:
- Flattening a 2D list
- Building a multiplication grid

---

## Testing

Pytest files are available in the `tests/` folder for validating all comprehension modules.
