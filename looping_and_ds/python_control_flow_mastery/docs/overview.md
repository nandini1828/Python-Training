# Control Flow Overview

This module focuses on Python conditional control flow and decision making.

## Implemented Topics

### 1. if-elif-else
Implemented in:

- `conditionals/if_else.py`

Examples:
- Number classification
- Pass/Fail decision

---

### 2. Truthy and Falsy
Implemented in:

- `conditionals/truthy_falsy.py`

Examples:
- Empty list, dict, set, string
- None and zero
- Non-empty collections and non-zero integers

---

### 3. Logical Operators
Implemented in:

- `conditionals/logical_operators.py`

Examples:
- and
- or
- not
- Access validation

---

### 4. Short-Circuit Evaluation
Implemented in:

- `conditionals/short_circuit.py`

Examples:
- Returning first truthy value
- Safe conditional checks

---

### 5. Ternary Operator
Implemented in:

- `conditionals/ternary.py`

Examples:
- Voting eligibility
- Even/Odd classification

---

### 6. match-case
Implemented in:

- `conditionals/match_case.py`

Examples:
- Day categorization
- Traffic signal handling


---
