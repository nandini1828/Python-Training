# Python Loops Mastery

This project demonstrates Python loop concepts in a clean, modular structure.

## Topics Covered

### Loop Foundations & Basic Iteration
- for loops
- while loops
- break
- continue
- pass
- for-else
- while-else

### Testing
Pytest-based unit tests are included for all major loop modules.
