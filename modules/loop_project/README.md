# Loop Project

## Objective

This project demonstrates Python looping concepts using modular programming.

## Topics Covered

- for loops
- while loops
- break
- continue
- pass
- for-else
- while-else

## Project Structure

```
loop_project/
│
├── main.py
├── pytest.ini
├── requirements.txt
├── README.md
│
├── loops/
└── tests/
```

## Running the Project

```
python main.py
```

## Running Tests

```
pytest
```

## Coverage Report

```
pytest --cov=loops --cov-report=html
```

Open

```
htmlcov/index.html
```

to view coverage.
