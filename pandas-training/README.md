# Pandas Training

This repository is a structured hands-on Pandas learning module.

## Goals
- Learn Pandas from basics to intermediate level
- Practice Series, DataFrame, CSV handling, filtering, cleaning, grouping, merging, and reshaping
- Build confidence with real datasets and mini analysis tasks

## Project Structure

```text
pandas-training/
├─ datasets/
├─ notes/
├─ src/
└─ exercises/
```

## Topics Covered
1. Getting Started with Pandas
2. Looking at Data
3. Selecting and Filtering
4. Cleaning and Editing
5. Grouping, Sorting, and Combining
6. Intermediate Pandas
7. Practice Projects

## How to Run

Create a virtual environment and install requirements:

```bash
pip install -r requirements.txt
```

Run a file:

```bash
python src/01_getting_started/01_series_dataframe.py
```

## Datasets
- employees.csv
- sales.csv
- students.csv

These datasets are used throughout the examples and exercises.
