# Pandas Core Concepts

This project demonstrates the most commonly used Pandas concepts in a modular way.

## Topics Covered

1. Getting Started
   - Import Pandas
   - Series
   - DataFrame
   - Read CSV
   - Save CSV

2. Data Inspection
   - head()
   - tail()
   - info()
   - describe()
   - shape
   - value_counts()
   - unique()

3. Selection & Filtering
   - Selecting columns
   - loc
   - iloc
   - Filtering
   - Multiple Conditions

4. Data Cleaning
   - isnull()
   - fillna()
   - dropna()
   - New Columns
   - astype()
   - drop()
   - rename()
   - drop_duplicates()

5. Grouping & Combining
   - sort_values()
   - groupby()
   - merge()
   - concat()

## Run

```bash
pip install -r requirements.txt
python main.py
```
