# Installation

Clone repository

```bash
git clone <repo-url>
```

Create virtual environment

```bash
python -m venv .venv
```

Activate environment

Mac/Linux

```bash
source .venv/bin/activate
```

Windows

```bash
.venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```
