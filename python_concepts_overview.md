# Python Concepts Overview

This document summarizes the contents of the three Python files in this workspace: `OOPS.py`, `datatypes.py`, and `datastructures.py`.

## 1. OOPS.py

`OOPS.py` introduces Object-Oriented Programming (OOP) in Python.

Key topics covered:
- Class and object basics
- Constructors (`__init__`)
- Instance variables and methods
- Encapsulation using private variables and getter methods
- Inheritance and method overriding
- Polymorphism through shared method names
- Abstraction with `ABC` and `abstractmethod`

This file demonstrates how to define classes, create objects, and use core OOP principles.

## 2. datatypes.py

`datatypes.py` explains Python core data types and common operations.

Key topics covered:
- Basic data types: integer, float, string, boolean
- Collection types: list, tuple, set, dictionary
- Printing and checking types with `type()`
- String methods: `upper()`, `lower()`, `title()`, `capitalize()`, `replace()`, `split()`, `find()`, `count()`, `startswith()`, `endswith()`
- List methods: `append()`, `insert()`, `remove()`, `pop()`, `sort()`, `reverse()`, `len()`
- Dictionary methods: `get()`, adding keys, `keys()`, `values()`, `items()`, `pop()`
- Set methods: `add()`, `remove()`, `union()`, `intersection()`

This file is a reference for working with Python data types and their common built-in methods.

## 3. datastructures.py

`datastructures.py` demonstrates Python data structures and how to use them.

Key topics covered:
- List usage: indexing, adding, removing, updating items, length, and loops
- Tuple usage: immutability and indexing
- Set behavior: unique values, adding and removing elements, membership testing
- Dictionary usage: key-value storage, access, modification, iteration
- String basics: indexing, length, iteration
- Stack implementation example using a list with `append()` and `pop()`

This file focuses on practical examples of Python data structures and their real-life analogies.

## Summary

Together, these files cover the fundamentals of Python:
- `OOPS.py` covers object-oriented programming concepts.
- `datatypes.py` covers built-in Python data types and useful methods.
- `datastructures.py` covers basic data structure usage and examples.

These resources are useful for beginners learning Python programming concepts and core language features.
