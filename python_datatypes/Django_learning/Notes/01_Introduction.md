# What is Django?

Django is a high-level Python Web Framework used to build web applications quickly, securely, and efficiently.

It provides many built-in features such as:

- URL Routing
- Database ORM
- Authentication
- Admin Panel
- Security
- Forms
- Sessions
- Middleware
- Templates

Instead of building everything from scratch, Django gives us ready-made components.

---

# What is a Framework?

A framework is a collection of pre-written code that helps developers build applications faster.

Without a framework:

You have to write:

- HTTP Handling
- URL Routing
- Database Connection
- Authentication
- Security
- HTML Rendering

With Django:

Most of these are already implemented.

You only write your business logic.

---

# Real Life Example

Suppose you are building an Online Shopping Website.

Without Django:

You need to build:

- Login System
- Registration
- Password Reset
- Admin Dashboard
- Database Connection
- Routing
- Security

Everything from scratch.

With Django:

These features already exist.

You simply configure and customize them.

# Backend Explained

Frontend

Responsible for:

- Buttons
- Forms
- Colors
- Layout
- User Interface

Backend

Responsible for:

- Business Logic
- Authentication
- Database
- APIs
- Security

Django is a Backend Framework.

# Django Terminology

Framework

A collection of reusable code.

Project

A complete web application.

App

A module inside a project.

Model

Represents Database Tables.

View

Contains Business Logic.

Template

HTML Page.

URL

Maps a request to a View.

ORM

Converts Python code into SQL queries.
