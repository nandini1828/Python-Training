# Loops Overview

This module focuses on Python loop foundations and basic iteration.

## Implemented Topics

### 1. for Loops
Implemented in:

- `loops/for_loops.py`

Examples:
- Iterating over a list
- Iterating over a string
- Iterating over a range

---

### 2. while Loops
Implemented in:

- `loops/while_loops.py`

Examples:
- Counting from 1 to n
- Summing values using a loop

---

### 3. break and continue
Implemented in:

- `loops/break_continue.py`

Examples:
- Breaking when first even number is found
- Skipping even numbers using continue

---

### 4. pass
Implemented in:

- `loops/pass_statement.py`

Examples:
- pass inside loop
- pass inside conditional block

---

### 5. for-else and while-else
Implemented in:

- `loops/loop_else.py`

Examples:
- Search using for-else
- Completion logic using while-else

---
