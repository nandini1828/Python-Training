# Loop Foundations & Basic Iteration

## Overview

Loops allow programs to perform repetitive tasks efficiently without duplicating code. Instead of writing the same statements multiple times, Python provides looping constructs that iterate over collections or repeat execution until a condition changes.

This module demonstrates these concepts through an **Inventory Management System** that processes products, deliveries, inspections, and searches.

---

## Concepts Covered

### for Loop

The `for` loop iterates over sequences such as lists, tuples, dictionaries, strings, and ranges. It is the preferred looping mechanism whenever the number of iterations is known or when working with collections.

### while Loop

The `while` loop repeatedly executes a block of code as long as a condition remains true. It is commonly used when the number of iterations is unknown beforehand.

### break

The `break` statement immediately terminates a loop once a required condition is met.

### continue

The `continue` statement skips the current iteration and moves directly to the next iteration without stopping the loop.

### pass

The `pass` statement acts as a placeholder and allows developers to define incomplete logic without causing syntax errors.

### for-else and while-else

Python provides an `else` clause for loops, which executes only if the loop completes normally without encountering a `break` statement. This feature is commonly used in searching algorithms.
