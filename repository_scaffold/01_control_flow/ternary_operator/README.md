# Ternary Operator

## Overview

The ternary operator provides a concise way to write conditional expressions in a single line. It improves readability for simple decisions and assignments.

Syntax:

```python
value_if_true if condition else value_if_false
```

---

## Learning Objectives

- Understand ternary expressions.
- Replace simple if-else statements.
- Improve code readability.
- Know when to use and avoid ternary operators.

---

## Topics Covered

- Basic Ternary
- Nested Ternary
- Conditional Assignment
- Function Arguments
- Real-world Examples
- Best Practices

---

## Example

```python
age = 20

status = "Adult" if age >= 18 else "Minor"

print(status)
```

Output

```
Adult
```

---

## Best Practices

- Keep ternary expressions simple.
- Avoid deeply nested ternaries.
- Prefer readability over shorter code.

---

## Summary

The ternary operator is useful for simple conditional assignments while keeping code compact and readable.
