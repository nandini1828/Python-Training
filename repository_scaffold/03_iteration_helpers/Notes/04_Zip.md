# 📌 zip() in Python

---

## 🧠 What is `zip()`?

`zip()` is a built-in function used to **combine multiple iterables** (like lists, tuples, strings) into a single iterable of tuples.

It allows you to iterate over multiple sequences **in parallel**.

---

## 🔹 Syntax

```python
zip(iterable1, iterable2, ...)
