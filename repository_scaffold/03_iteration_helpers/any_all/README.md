# any_all

This module explains Python's any() and all() functions.

---

## Topics Covered

- any() function
- all() function
- truthy and falsy values
- condition-based checks
- generator expressions

---

## Key Concepts

- any() → True if at least one element is True
- all() → True if all elements are True
- short-circuit evaluation
- works with any iterable

---

## Syntax

any(iterable)
all(iterable)

---

## Important Note

- any([]) → False
- all([]) → True

---

## Run

python -m any_all.demo
