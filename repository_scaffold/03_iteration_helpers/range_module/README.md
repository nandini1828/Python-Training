# range_module

This module demonstrates practical usage of Python's `range()` function.

## Features

- Generate sequence of numbers
- Custom step ranges
- Even and odd number filtering
- Summation using range

## Functions

- generate_numbers(n)
- generate_custom_range(start, stop, step)
- even_numbers(n)
- odd_numbers(n)
- sum_of_range(n)

## Run Demo

```bash
python -m range_module.demo
```
