# reversed_module

This module explains usage of Python reversed() function and slicing.

---

## Topics Covered

- reversed() function
- slicing technique [::-1]
- reversing lists, tuples, strings
- reversing words and sentences
- palindrome checking

---

## Key Points

- reversed() returns an iterator
- Works only with iterable objects
- slicing works only with sequence types

---

## Run

python -m reversed_module.demo
