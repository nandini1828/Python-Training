# sorted_module

This module demonstrates Python sorted() function in depth.

---

## Topics Covered

- Basic sorting
- reverse sorting
- sorting strings
- key functions
- sorting dictionaries
- sorting tuples
- case-insensitive sorting
- stable sorting concept

---

## Key Concepts

- sorted() returns a NEW list
- original data remains unchanged
- key parameter is powerful
- stable sorting preserves order

---

## Syntax

sorted(iterable, key=None, reverse=False)

---

## Run

python -m sorted_module.demo
